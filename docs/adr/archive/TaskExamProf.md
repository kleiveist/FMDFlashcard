## Tabelle der Eigenschaft Verhalten in der Exam Task Auswahl

In den Markdown Dateien sind unter den Block Eigenschaften unter Task die Examsprofile zugeordnet  
beim Anklicken nur einer Aufgabe soll das jeweilige Examsprofil automatisch gewählt werden  
Fallback ist Standard Profil falls kein Attribut Task vorhanden ist

| Exam.md mit Typ Task                 | Selection                                          | Wenn                                   | Task Profil | Standard Profil | Verhalten Punkte   | Task Anzahl        | VerhaltenZeit    |
| ------------------------------------ | -------------------------------------------------- | -------------------------------------- | ----------- | --------------- | ------------------ | ------------------ | ---------------- |
| Auswahl einer Exam                   | alle                                               | In Markdown Eigenschaftvorhanden       | Ja          | nein            | Task Profil Punkte | Task Profil Anzahl | Task Profil Zeit |
| Auswahl einer Exam                   | alle                                               | In Markdown Eigenschaftnicht vorhanden | nein        | ja              | StandardPunkte     | StandardAnzahl     | Standard Zeit    |
|                                      |                                                    |                                        |             |                 |                    |                    |                  |
| Ab zwei gleiche Exams                | Nested                                             | Größer Eins                            | Ja          | nein            | Task Profil Punkte | Task Profil Anzahl | Task Profil Zeit |
| Ab zwei gleiche Exams                | Sequential + internal shuffleSequentialFully mixed | Größer Eins                            | nein        | ja              | StandardPunkte     | StandardAnzahl     | Standard Zeit    |
| mehr als Zwei gleiche Exams          | Nested                                             | Größer Zwei                            | Ja          | nein            | Task Profil Punkte | Task Profil Anzahl | Task Profil Zeit |
| mehr als Zwei gleiche Exams          | Sequential + internal shuffleSequentialFully mixed | Größer Zwei                            | nein        | ja              | StandardPunkte     | StandardAnzahl     | Standard Zeit    |
|                                      |                                                    |                                        |             |                 |                    |                    |                  |
| Ab zwei unterschiedliche Exams       | Nested                                             | Größer Eins                            | nein        | ja              | StandardPunkte     | StandardAnzahl     | Standard Zeit    |
| Ab zwei unterschiedliche Exams       | Sequential + internal shuffleSequentialFully mixed | Größer Eins                            | nein        | ja              | StandardPunkte     | StandardAnzahl     | Standard Zeit    |
| mehr als Zwei unterschiedliche Exams | Nested                                             | Größer Zwei                            | nein        | ja              | StandardPunkte     | StandardAnzahl     | Standard Zeit    |
| mehr als Zwei unterschiedliche Exams | Sequential + internal shuffleSequentialFully mixed | Größer Zwei                            | nein        | ja              | StandardPunkte     | StandardAnzahl     | Standard Zeit    |
