\section{Migrationsevidenz}
\label{app:migration-evidence}

Die Migrationsevidenz unterscheidet eine historische Version, ein erhaltenes State-Format,
den Austausch beider Payload-Verzeichnisse und eine registrierte Reconciliation. Produkt-
und unbekannte Dateihashes bleiben dabei außerhalb der verwalteten Migration. Details und
Testbezug stehen in \texttt{evidence/claims.toml} unter \evidence{EV-UPGRADE-001}.
