\section{CI and system testing}
\label{chap:ci-system-testing}

The test pyramid combines units, adapter contracts, integration cases, copy fixtures, and
documentation checks. The copy matrix keeps Linux, Windows, and macOS results as
not-yet-recorded \Measured{} evidence rather than presenting platform-neutral tests as
real customer-project results. Synthetic fixtures are not described as customer projects.

Figure~\ref{fig:ci-test-pyramid} places the test levels in context; Figure~\ref{fig:os-fixture-matrix}
shows the outstanding operating-system and fixture evidence.
