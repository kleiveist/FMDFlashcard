\section{Profile and adapter model}
\label{chap:profile-adapter-model}

The five profiles \texttt{web-only}, \texttt{web-cloud}, \texttt{desktop-local},
\texttt{desktop-cloud}, and \texttt{full-platform} select capabilities instead of a
complete product tree. Feature dependencies are resolved before adapters detect, plan,
apply, and verify. Profile resources and the adapter contract are documented as
\Implemented{} and \Verified{} (\evidence{EV-PROFILES-001}).

Figure~\ref{fig:profile-resolution} shows resolution from the selected profile
through features to adapter selection.
