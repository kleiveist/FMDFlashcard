\section{Abstract}
\label{chap:abstract}

This case study examines a tooling package that can be copied directly into existing
software projects. It owns neither application code nor the product lifecycle. Instead,
it resolves a \ProjectContext{}, detects technical markers, selects a profile, and plans
bounded changes. The study evaluates portability, ownership protection, idempotence,
recovery, and inspectable documentation.

The analysis relies on source code, copy fixtures, and reproducible test references. It
does not report invented runtimes or success rates: platform and PDF measurements that
have not yet been collected remain explicitly \Planned{} or a \Limitation{}.
