\section{Evaluation}
\label{chap:evaluation}

The evaluation uses demonstrable properties: stable hashes of product-owned files, a
read-only check, an empty second plan, restoration after an injected failure, and the
consistency of an exported payload. Its design separates \Implemented{}, \Verified{},
and \Measured{}; the last category requires a reproducible run with version, commit,
runner, and toolchain data. Portable export is registered as \Verified{}
(\evidence{EV-EXPORT-001}).

Figure~\ref{fig:export-boundary} makes the boundary visible between the exported
tooling payload and non-portable project or build files.
